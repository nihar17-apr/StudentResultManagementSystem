# Student Result Management System

## Overview
A Java Swing desktop application developed using JDBC and MySQL for managing student academic records.

## Features
- Admin Login Authentication
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Student Count Dashboard
- Export Student Report PDF
- Automatic Grade Calculation

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- SQL

## Tools Used
- VS Code
- MySQL Workbench

## Database
MySQL database used for storing student records and admin credentials.
